# 日常活跃不足修复

## 目标与已确认问题

完整日常必须达到至少 100 活跃，并领取全部五档活跃宝箱。任务调度正常结束不能代替该结果。

真机确认：现有拟战场域的最大次数可以正常执行；临期血清的旧图标匹配未命中，导致既有补给分支被跳过。领取任务没有助理交流步骤，且低活跃分支返回主页后仍算成功。

## 实施选择

优先修复现有任务链，不增加一套重复的日常调度器，也不通过无上限重跑或开启黑卡兑换补活跃。

1. 拟战场域沿用原有“使用临期体力”开关。进入血清面板改用同帧主页判断和血清数量识别，继续使用既有期限判断、选择和退出流程；不扩大补给包使用范围。
2. 领取任务先回到已识别主页，点击助理头部后立即识别“交流”菜单并进入，确认角色档案“基本信息”页再返回、进入原每日/每周/勤务领奖链。当前涂装胸前区域在从任务页返回后的点击或长按都会触发全屏互动动画；同起点的头部点击已验证可进入交流，不能将播放语音、动画或单次长按当作完成。菜单未出现或档案未进入时走失败收尾。日服入口覆盖一并跟随，保留原语言流程区别。其他语言词条仅通过资源加载与合成测试，仍需相应游戏界面验收。
3. 领取后检查活跃值和五个宝箱的已领标记。已领状态可重复运行而不重复点宝箱；低活跃先领取当前奖励，再通过既有失败收尾明确报告未完成。
4. 复测收起主页菜单时，展开箭头偏出旧 ROI，公会入口无法找到。复用原箭头模板扩大限定区域，并要求同帧主页识别，自动展开后沿原任务链执行；不对非主页做通用点击。

## 验证与边界

- 原生内存回归覆盖主页与非主页、补给开关、有/无临期包、低活跃和全部宝箱已领/部分未领、重复运行及错误分支。
- 私有真实帧仅在根目录 ignored debug 回放，不作为版本化夹具。
- 运行相关回归、六套资源 Schema 和加载检查，然后通过正常 App 日常入口实测，核对实际活跃、五档宝箱及固定提示。
- 当前血清与允许使用的补给仍不足时，明确报告未完成，不假造成功或购买黑卡体力。
- 保留原工作区修改，不提交或推送。回退仅限本次相关节点、文案和测试。
