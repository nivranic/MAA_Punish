# 血量背景尾字复核

矩阵首战同一轮连续六次把满血识别成 `10823/10823VV`，严格血量解析拒绝，最终在入场预算内失败。原始画面显示血量区域右侧的屋顶纹理；同帧回放中原识别带尾字，已有白字过滤读到完整且数字不变的分数。全程启用过滤则会丢失已观察到的零血量，因此保留正常读取。

复用现有隔离 Context 的同帧复核：只在唯一 OCR 结果为完整有效分数加英文字母尾字、且与原最佳结果一致时，使用已有白字过滤再读一次。新结果须通过完整严格解析，分子、分母与原结果逐字一致；任一数字改变、内部混字、多结果、停止或识别失败都保持未知。零血量仍为死亡，不赋予输入许可。

不修改血量解析器、校准缓存、识别阈值或入场等待预算。验证包括数字一致性、零血量、歧义与停止边界，合成图原生复核、原始帧回放和同版真机重新入场；真实证据仅存根目录被忽略的 `debug/`。
