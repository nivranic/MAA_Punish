# 矩阵套装激活弹窗收尾

真机三场战斗获胜后，商店奖励使装备凑齐套装，出现“套装已激活 / 具体效果”说明。原装备确认仍能识别背景上变暗的“确定”，进入红位分配子链；弹窗遮住了色位区域，子链没有处理该弹窗，超时后正确记为任务失败。

补充只识别这两个标题的关闭节点，点击说明面板之外的空白处。矩阵主分派通过 JumpBack 调用；已进入装备确认子链时，关闭后直接交回父流程重新观察页面，不在子链内重复确认可能已经消费的装备。保持装备色位、选中边角和确认按钮的原有校验，不使用全局盲点或删除色位门禁。

仅增加父流程的弹窗路由不能覆盖已进入的装备子链；延长等待也不能关闭需要用户点击的说明，因此不采用。新增识别支持已确认的简体与对应繁体文字，其他语言的真实画面仍待验收。

原生流程回归覆盖两种入口及标题缺失时不得输入，真实原始帧单独回放，真机后续套装激活再验证。失败弹窗不是最终结算，不得将关闭成功记为矩阵通关。
