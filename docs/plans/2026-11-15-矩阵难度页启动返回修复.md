# 矩阵难度页启动返回修复

战败结算自动重开后，停止在“选择难度”页。再次运行“进入游戏”时，画面持续更新，但启动分派没有该页的返回路径，反复执行打开应用和计数器，不能将其误判为截图冻结。

正常导航对照确认：左上角返回进入矩阵主页，主页已有主界面入口。增加只读难度标题、矩阵特有的“堆栈潜伏”名称识别；两者和返回文字必须同帧成立，才点击返回。启动及返回主菜单子链复用同一处理器，保留原难度选择及存档逻辑，不推进难度或消费材料。

新增原生回归覆盖两个入口、四个资源语言组合，以及标题、卡片、返回按钮缺失的拒绝分支。旧资源 8 项失败、24 项通过；原图回放覆盖有效难度页、遮挡三个必要条件、矩阵主页和剧情页。真实图片仅存被忽略的 `debug/`。

修复后相关 104 项回归、6 个原图正负检查、基础资源 Schema 和六套资源加载通过。简体真机从同一难度页自动执行新返回节点，随后回到主页并继续矩阵招募，现场返回已通过；其他语言尚未游戏验收。撤回仅涉及新增三个节点、两个接入点及配套测试，不撤销既有矩阵战斗和事件修复。
