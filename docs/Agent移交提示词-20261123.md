## 三、已定型修复与关键语义（接手前必读，避免重复踩坑）

- **缺陷台账**：R01 链累计 63-69 号（78-86 批）；矩阵链 54-62 号。全部在台账 2.315-2.319。
- **MaaFw 语义铁律**（每条都实锤过）：
  - 主 timeout 需覆盖过渡链（父节点默认 20s 会误杀 >20s 的子链，如编队→作战开始→加载）；
  - DirectHit 恒真节点带 target 引用锚，画面流转后 action 秒级 Failed——用固定坐标 Click `[x,y]` 或 `[x,y,w,h]`；
  - 节点 timeout 覆盖自身 next 列表预算；next 末位无 next 节点=假 COMPLETED 终结器；
  - [JumpBack]X=X 命中执行完后回当前链列表头循环，未命中只是继续扫；
  - 跨文件同名 key=native 加载爆炸；资源侧 next 引用须资源 bundle 内已定义；
  - 热路径恢复节点必须带自有 on_error（否则 Default.on_error→优雅退出杀 run）；
  - And(all_of:[节点名]) 复用他人识别锚是惯用法；OCR 无阈值包含匹配会噪声误命中（加 threshold）；
  - only_rec+非空 expected 列表组合曾整链失效。
- **共享节点改动风险**：`战斗中`（Auto_Battle.jsonc）是全模式共享战斗 HUD 锚（TemplateMatch 右上暂停键 roi[1090,0,190,100] + Custom CombatRunner）。BOSS 战 HUD 变体→裁新模板追加 template 列表（战斗中BOSS.png 先例），阈值 0.6 不动。
