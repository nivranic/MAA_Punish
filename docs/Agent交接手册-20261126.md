## 6. 环境坑（都是实打实踩过的）

- `pwsh` 沙箱写入范围随会话策略变化：本轮（DSH danger-full-access）`debug/`、`docs/`、`resource/` 写入均可用；早前会话实测被拒时应改用 `write`/`edit` 工具，**不要**申请提权绕过。`py_compile` 因写 `__pycache__` 失败属权限拒绝、不是语法错，可用 `ast.parse` 代替。
- **设备上有两个包，资源目录各一套**：日常/验收 run 用的是 `com.overflow65537.maafw.punish.iqoo16`（**3.12.10-iqoo.2375**，11-14；bundle **含** `日常账本准入`，`files/pi/resource/base/pipeline` mtime 2026-11-26 23:38）；另一个 `com.overflow65537.maafw.punish` 是 **3.12.13**（11-25 20:27，发版资源，`grep -rl 日常账本准入` 0 命中）。推文件前先 `pm list packages | grep maafw` 并用「pipeline 目录 mtime + 是否含 `日常账本准入`」判定该推哪个包；对 3.12.13 整份推工作区文件会引用不存在的节点（11-27 00:4x 我就先推错了包，已还原，见 `mizhan/README.md` §4）。

- `screencap -d` 需要 SurfaceFlinger 长 id，短 displayId 会报 `Display Id '13' is not valid`。
