目标是逆冕首发、默认留场，按“补刃意 → 已激活红球优先、蓝球可替代 → 必要踏破结算 → 单体蓄力大或多波斩切 → 重建资源”循环。必要长普优先于大招 ready；结算未确认时保留 pending。多波完整入相、长期循环和条件辅助仍须分别实现与验收。

## 客户端已确认的基础机制

以下条件来自[当前客户端技能摘录及原图](../build-debug/iqoo16-inverse-replay-20261023/current-client-skill-excerpts-20261024.md)，描述静态规则。数值发生变化时应重新读取目标客户端。

| 行为 | 条件和会影响策略的结果 |
| --- | --- |
| 夕照 | 行者相点击黄色信号球；按消球数获得120/240/360刃意。 |
| 追迹 | 行者相点击普攻；四段分别获得30/50/100/180刃意。点击次数与实际完成段数分别核实。 |
| 源响／终声 | 行者相、360刃意、长按已激活红／蓝球；满蓄消耗全部刃意，切刀并进入深渊相，获得90厄债、25航迹。未激活时的点按换刀另有路径。 |
| 踏破 | 深渊相点击／长按普攻；释放期间无敌并暂停相倒计时，期间无法催发／枯折。大／小太刀末段均获得90厄债，并强制退出深渊相。 |
| 万劫 | 360厄债，长按必杀至蓄力完成后释放终结必杀。满蓄与终结完成分别观察。 |
| 断念 | 360厄债，必杀蓄力条未满时松手；进入专用斩切阶段，普攻键点击／长按可自动消斩切球，耗尽后自动终结。再次点击必杀或倒计时结束可提前终结并结算剩余球伤害。基础正文为8球，实际阶级增量另核。 |

刃意上限360；达到上限激活红／蓝球，消耗完之前无法继续获取刃意。基础深渊相在1秒后自动退出，三消寂夜及催发／枯折刷新倒计时，踏破／归渊暂停倒计时；这个窗口与蓄力所需时间分别处理，见[首发与资源证据](../build-debug/iqoo16-start-resource-evidence-20261024/receipt.json)。本批已读阶级条款未列相倒计时变化，其他装备、技能或局内增益另核。

无想属于**行者相＋长按普攻**，需要与深渊相踏破区分。三张完整页已[独立亲看、转录并核hash](../build-debug/iqoo16-wuxiang-text-20261024/report.md)：释放获得30刃意，精准释放转为90；大太刀长按至武器发光后松手，上挑消耗250闪避值，空中点击可追加攻击，期间长按精准松手可连续剑气；小太刀普通松手后闪消耗250闪避值，身体发光时精准松手的剑气不耗闪避值且可连续。两种刀的发光反馈分别校准，精准窗口与实际时长仍待实战。原图含账号界面信息，仅保留本地证据。
